## 考试基本信息(来自官方 exam guide)

- 65 题:**50 题计分 + 15 题不计分**(不标注哪些是不计分的)

### ⚠️ 针对"零上手经验"的最重要提醒

### Day 3(09-10):DynamoDB
- **RCU/WCU 计算(必须形成肌肉记忆)**:
  - 强一致读:1 RCU = 4KB/s
  - 最终一致读:1 RCU = 2 × 4KB/s(即 4KB 算 0.5 RCU)
  - 事务读:4KB 算 2 RCU
  - 写:1 WCU = 1KB/s;事务写 = 2 WCU
  - 计算时**先把 item 大小向上取整到 4KB / 1KB 的倍数**
- Partition Key 设计:**高基数、避免热分区**(Skill 1.3.1)
- Query vs Scan 的差异(Skill 1.3.3)
- LSI vs GSI(LSI 建表时定、共享表容量、同 partition key;GSI 可后加、独立容量、只支持最终一致读)
- **Optimistic Locking:`ConditionExpression`**
- `BatchGetItem` / `BatchWriteItem` 的部分失败处理 → **指数退避 + 抖动重试**
- TTL、DynamoDB Streams + Lambda、DAX
- ProvisionedThroughputExceededException 怎么处理

微验证:用 CLI 或 boto3 跑一次带 `ConditionExpression` 的 `put_item`,故意让条件不满足,看返回的错误。

### Day 6(09-13):Elastic Beanstalk + IaC【原计划严重低估的一天】
**Elastic Beanstalk(送分题重灾区)**:
- 六种部署策略,重点记 **停机时间 / 是否需要额外实例 / 回滚速度**:
  - All at once(有停机,最快,失败要重新部署)
  - Rolling(无停机,容量临时下降)
  - Rolling with additional batch(无停机,不降容量,多花钱)
  - Immutable(新建一批实例,最安全,回滚最快,成本最高)
  - Blue/Green(独立环境 + swap URL)
  - Traffic splitting(canary 式按比例切流)
- `.ebextensions` 配置文件、环境变量、EB CLI
- Worker environment 与 `cron.yaml`

**CloudFormation / CDK / SAM(三者关系)**:
- CloudFormation:intrinsic functions(`Ref`、`Fn::GetAtt`、`Fn::Sub`、`Fn::ImportValue`)、Parameters / Outputs / Mappings / Conditions、change sets、nested stacks、`DeletionPolicy`
- SAM 是 CloudFormation 的扩展(`Transform: AWS::Serverless-2016-10-31`)
- CDK:用编程语言生成 CloudFormation,`cdk synth / deploy`

**AppConfig**(Skill 3.1.5 直接点名):环境配置管理、feature flags、部署策略与自动回滚

### Day 7(09-14):安全与认证【Domain 2 占 26%,这一天很重】
- **Cognito:User Pools vs Identity Pools**(高频混淆点)
  - User Pool = **认证**,返回 JWT(ID token / access token / refresh token)
  - Identity Pool = **授权**,拿 token 换**临时 AWS 凭证**
  - 两者串联的完整流程要能画出来
- **KMS**:
  - **信封加密(Envelope Encryption)全流程**
  - `GenerateDataKey`(返回明文+密文两份)vs `GenerateDataKeyWithoutPlaintext`
  - `Encrypt` / `Decrypt` 的 4KB 限制(超过就必须用信封加密)
  - Key Policy vs IAM Policy vs Grants
  - 自动轮换开关(Skill 2.2.7)、跨账户加密(Skill 2.2.6)
- **Secrets Manager vs Parameter Store**:需要自动轮换 → Secrets Manager;纯静态参数、要免费 → Parameter Store SecureString(**你个人项目正在做这个决策,直接拿来当案例**)
- **STS**:`AssumeRole`、`AssumeRoleWithWebIdentity`(你 SAA 学 IRSA 时已经碰过)
- 敏感数据:环境变量加密、数据脱敏/masking(Skill 2.3.5)、多租户数据访问模式(Skill 2.3.6)
- Certificate 管理、ACM / Private CA(Skill 2.2.2)

微验证:CLI 跑一次 `aws kms generate-data-key`,看返回的 `Plaintext` 和 `CiphertextBlob` 两个字段。
